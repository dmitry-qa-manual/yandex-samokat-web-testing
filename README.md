# Yandex Samokat — Web Testing

## 📋 Project Overview

This project was completed as part of the Yandex Practicum Software Testing course.

The goal was to test the Yandex Samokat web application and verify its functionality, usability and behavior under different conditions.

## 🔍 Testing Activities

- Requirements analysis
- Test analysis and test design
- Functional testing
- Regression testing
- Cross-browser testing
- Testing different screen resolutions
- Boundary value analysis
- Equivalence partitioning
- Decision tables
- Bug reporting

## 🧪 Test Environment

- Yandex Browser
- Google Chrome
- Screen resolutions: 1280×720 and 1920×1080

## 🐞 Bug Reporting

During testing, defects were identified, documented and reported with steps to reproduce, expected results and actual results.

## 📚 Skills Demonstrated

- Test Analysis
- Test Design
- Checklists
- Test Cases
- Bug Reporting
- Web Application Testing
- Requirements Analysis

## 🎯 Result

The project provided practical experience in analyzing requirements, designing tests, executing test cases and documenting defects in a web application.
